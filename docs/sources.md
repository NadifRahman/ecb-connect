# Sources and currency

These guides are newly written for ECBE Connect. They do not reproduce the source documents or
their screenshots.

## Supplied source documents

- *Remote Desktop To Access Cadence via VNCconnect*, dated July 28, 2020 and updated September 26,
  2020. It documents RealVNC installation, `vncconnect`, SSH tunneling, VNC-password management,
  listing/killing sessions, and multiple local displays.
- *Steps to vnc*, a four-page user capture showing a 2026 connection to Pascal, required password
  and verification-code prompts, an assigned `cmp92.ee.ryerson.ca` workstation, and remote VNC port
  5902.
